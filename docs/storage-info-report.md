# Технический отчет: блок «Информация о хранилище» в Профиле

Дата: 2026-09-27

## Задача

Добавить в раздел Профиль (app/settings) блок с информацией о локальном
хранилище: занимаемое/доступное место через `navigator.storage.estimate()` и
статистика записей из локальной базы IndexedDB (Dexie).

## Изменения

| Файл | Тип | Что сделано |
| --- | --- | --- |
| `components/storage-section.tsx` | новый | Клиентский компонент с двумя карточками: «Хранилище» и «Статистика» |
| `app/settings/page.tsx` | правка | `<StorageSection />` вставлен после `<SyncSection />`, перед `<SignOutButton />` |

## Компонент `StorageSection`

Оформление повторяет существующие разделы Профиля: `bronze-card bronze-edge`,
заголовки `font-chronicle` золотом, строки `flex justify-between` с подписями
в `--ink-secondary`, значения без технического жаргона. Сервер не вызывается —
блок полностью локальный.

### 1. Размер хранилища (`navigator.storage.estimate()`)

- Вызывается один раз в `useEffect` (параллельно с подсчётом статистики).
- Отображаются: «Используется», «Доступно» (quota − usage), «Заполнено»
  (usage / quota · 100%).
- Форматирование: Б / КБ / МБ / ГБ с одним знаком после запятой, хвостовой
  «.0» отбрасывается («4.3 МБ», «2.1 ГБ»); проценты — до 2 знаков, при
  значении меньше 0.01% — «<0.01%».
- Отсутствие поддержки, отсутствие `navigator.storage` / `usage` / `quota`,
  а также отказ promise показывают текст: «Информация о размере хранилища
  недоступна на этом устройстве.» (требование 4).

### 2. Статистика локальной базы (Dexie)

- «Записи Пути» — сумма четырёх журнальных таблиц стихий:
  `training + nutrition + learning + creation` (именно они образуют Путь в
  `path-client` / `readPathDay`).
- «Отметки» — `asceticismLogs` (отметки выполнения аскез); «Аскезы» —
  `asceticisms` (сами аскезы).
- «Дней истории» — число уникальных `entryDate` по тем же источникам, из
  которых собирается история в `readHistoryPage` (queries.ts): thoughts,
  training, nutrition, learning, creation, leisure, asceticismLogs. Ключи
  индекса `entryDate` читаются через `orderBy("entryDate").keys()` (без
  загрузки самих строк) и дедуплицируются в `Set`.
- Остальное — `table.count()`.
- Если база недоступна (нет `indexedDB`) или чтение упало — значения
  «—», блок статистики не скрывается (требование 4).

### 3. Мелочи реализации

- SSR-безопасность: на сервере `localDb()` возвращает `null`, значения
  рендерятся плейсхолдерами «…», реальный подсчёт — только в эффекте
  на клиенте. Флаг `cancelled` защищает от setState после размонтирования.
- Подсчёт и estimate выполняются в `Promise.all`, независимо друг от друга:
  отказ одного не мешает другому.
- Склонение «запись / записи / записей» — локальный `pluralRu`.

## Ограничения

- `usage` из `estimate()` — общее место origin (включая Cache Storage,
  Service Worker и пр.), поэтому оно может быть больше суммы записей базы.
- Значения — моментальный снимок при открытии Профиля; автообновления при
  появлении новых записей нет (обновляется при повторном заходе на страницу).
